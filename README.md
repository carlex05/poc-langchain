# poc-langchain

Sandbox repository with practical examples of LLM-powered agents and patterns. Each subfolder contains a small, runnable proof of concept that favors clarity over completeness.

## Projects
- `agentic-pipeline/`: Quarkus + LangChain4j POC that shows a pipeline pattern with planner, writer, and critic agents working in sequence. See `agentic-pipeline/README.md` for setup and usage.

More agentic demos will be added over time; structure new examples as self-contained folders with their own README and runnable instructions.
